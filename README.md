# METHODOLOGY

I scraped the Congress.gov site for all legislation, specifically bills (H.R. or S), that fell under the Science, Space, and Technology house committee. I scraped the sponsor name, party, state, district, co-sponsors and date the bill was introduced. The scrape went back to the very first bill heard in this committee, in 1951. 
I am using the BeautifulSoup (beautifulsoup4) package on Python to scrape this information, since I didn’t need Playwright on account of the code structure we were told to use for this project/didn’t need to do Headless=True or anything. For the first scrape, all entries are logged. But, subsequent scrapes will only capture new entries which cuts down on needless scraping (and the obvious byproducts of such usage).
The data points are each individual bill with the relevant info I laid out above. I am not filtering for potential duplicate data because each entry is logged and that can be done manually, since a person can then screen each duplicate case to see if it truly is an exact duplicate, which is a safer method. I had Claude Code write in a failsafe where if data can’t be scraped, I receive a “fail” message to my email, so I can then check the scraper and its info. This also opens a failure step on GitHub Issue so I can fix the issue, which only will run if there is an issue (not if there is a run with 0 new bills, for example).
I want to analyze if more bills in the realm of science, space, and technology are being passed now, in the current administration — or, if the passage rate is par for the course. I’m particularly interested in tracking gene therapy and biotechnology bills, since few journalists/researchers are looking at the speeding up of FDA/general legislation in this realm.
